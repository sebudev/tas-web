🔑 API tokens per bot

Memuat...
📌 Cara pakai untuk integrasi:
Kirim header Authorization: Bearer <token> pada request API.
Token ini terikat ke bot tertentu — semua operasi (list/upload/download/stream) otomatis memakai storage bot itu, tidak peduli bot mana yang sedang aktif di UI.

Contoh: curl -H "Authorization: Bearer tas_xxx" http://HOST:PORT/api/files
/api/stream dan /s/<token> tetap publik (capability URL by hash).
